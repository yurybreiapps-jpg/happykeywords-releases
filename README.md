# HappyKeywords releases

Downloads for **HappyKeywords**, App Store keyword research for Mac: [happykeywords.com](https://happykeywords.com).

This repository holds only the signed and notarized app files and the feed the app reads to update itself. There is no source code here.

- Get the latest version from the website, or from [Releases](https://github.com/yurybreiapps-jpg/happykeywords-releases/releases).
- Once installed, HappyKeywords updates itself: it checks for a new version at launch and every few hours, and installs it when you restart.
- Questions and bug reports: [happykeywords.com](https://happykeywords.com).
